# v0.6.0 — Final Model Freeze and Release Audit

## Overview

v0.6.0 freezes the final three-model VaR evaluation and records the release
audit evidence for Historical Simulation, EWMA, and Gradient Boosting G04.

This release focuses on reproducibility, artifact consistency, leakage
controls, documentation, and release readiness. It does not introduce new
model tuning or model selection.

## Final Evaluation Contract

The frozen evaluation contains:

- 1,194 prediction rows;
- 398 Historical Simulation forecasts;
- 398 EWMA forecasts;
- 398 Gradient Boosting forecasts;
- 398 common target dates;
- evaluation period: 2024-12-18 to 2026-07-28.

All models share the same target-date universe and actual portfolio returns.

Violation rule:

`actual_return < quantile_return`

VaR convention:

`VaR = max(0, -quantile_return)`

## Frozen Results

| Model | Forecasts | Violations | Violation Rate | Pinball Loss | Average VaR |
|---|---:|---:|---:|---:|---:|
| Historical Simulation | 398 | 27 | 6.78% | 0.001896 | 2.13% |
| EWMA | 398 | 22 | 5.53% | 0.001968 | 2.51% |
| Gradient Boosting G04 | 398 | 24 | 6.03% | 0.001758 | 2.33% |

Gradient Boosting G04 has the lowest aggregate Pinball Loss in this
evaluation, while EWMA has the violation rate closest to the nominal 5%
level.

These are criterion-specific observations. The release does not designate
a universal overall winner.

## Gradient Boosting Freeze

The frozen Gradient Boosting configuration is G04:

- alpha: 0.05
- estimators: 100
- learning rate: 0.03
- maximum depth: 2
- minimum samples per leaf: 5
- subsample: 1.0
- seed: 42

Frozen features:

- `return_lag_1`
- `return_lag_2`
- `return_lag_5`
- `rolling_vol_5`
- `rolling_vol_20`
- `rolling_vol_60`
- `drawdown`

G04 is not claimed to be a confirmed global winner across G01-G07.

No volume, price-range, VNINDEX, or other market features are included in
the frozen G04 implementation.

## Leakage and Temporal Audit

The independent B audit verifies the implemented feature construction,
including lag semantics, backward-looking rolling volatility, historical
drawdown construction, target exclusion, future perturbation, chronological
evaluation, and absence/disablement of shuffle.

The supported conclusion is:

> No direct target leakage was detected in the implemented feature
> construction.

This is deliberately narrower than claiming that every possible use of the
model is guaranteed leakage-free.

## Artifact Consistency

The release audit independently recomputes final metrics from
`results/final_predictions.csv`.

It verifies:

- prediction row counts;
- common target dates;
- evaluation boundaries;
- common actual returns;
- no duplicate method/date keys;
- no missing values;
- finite quantiles;
- finite VaR;
- non-negative VaR;
- strict violation semantics;
- VaR sign convention;
- violation counts and rates;
- Pinball Loss;
- Average VaR.

The independent release audit completes with:

`RELEASE_ARTIFACT_AUDIT_PASS`

## Paired-Comparison Context

Day-22 paired evidence should be interpreted alongside aggregate metrics.

For GB versus Historical:

- 151 dates favor GB;
- 247 dates favor Historical;
- mean GB-minus-Historical loss difference is negative.

Thus, GB's aggregate Pinball advantage over Historical is
magnitude-driven/concentrated rather than evidence that GB wins on most
dates.

For GB versus EWMA:

- 231 dates favor GB;
- 167 dates favor EWMA.

This represents a broader paired advantage for GB in that comparison, but
still does not establish a universal overall winner.

## Known Limitations

- G04 is not a confirmed G01-G07 global tuning winner.
- G04 uses only implemented return-history features.
- Volume features are not included.
- Price-range features are not included.
- VNINDEX/market features are not included.
- The final evaluation is not described as a pristine untouched test set.
- Aggregate metrics may conceal date-level and regime-specific behavior.
- Observed evaluation differences should not be interpreted as causal
  relationships.
- No model is designated as universally superior.

## Freeze Policy

v0.6 does not permit silent post-freeze modeling changes.

Any new feature engineering, hyperparameter tuning, model selection, or
replacement of canonical final predictions requires explicitly reopening
the modeling process and documenting the resulting evaluation changes.
